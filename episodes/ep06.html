#06 ランニングの初期衝動 ゲスト：桑原慶

2020-05-22 · 1h09m

コミュニティのちから / NikeRunFwd / 第一回UTMF / 天子山地全山縦走 / ベアフットテッドとメキシコ遠征 / エルドラゴン石川弘樹 / ランボーズ / ランニングで変わった人生

コロナによる自粛要請の中、健康維持のために増えてきたランナーたち。今回は、コミュニケーション力でトレイルランニングシーンを牽引してきた人気ショップ〈Run boys! Run girls!〉のオーナー桑原慶さんに、走り始めた頃の初期衝動からお店立ち上げまで、そして走り始めた人への継続するためのコツを伺いました。聞き手は、桑原さんと同時期にランニングを始めて並走してきたonyourmark編集長の松田です。
